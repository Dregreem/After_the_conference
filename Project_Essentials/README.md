# Project Essentials

Bu klasör, **Move-and-Sleep Güneş Takip Sistemi** projesinin tüm kritik dosyalarını içerir.

## Klasör Yapısı

| Klasör | Açıklama |
|--------|----------|
| `01_Main` | Ana simülasyon betiği (main_easy.m) ve yardımcı betikler |
| `02_Controllers` | PID, FLC ve FSM kontrolcüleri |
| `03_Physics` | Servo motor fizik modelleri (Teorik, DC Motor, İdeal) |
| `04_Sensors` | GL5528 LDR sensör modeli |
| `05_Sun` | Güneş pozisyonu ve PVGIS veri işleme |
| `06_Panel` | PV panel güç hesaplamaları |
| `07_Scenarios` | Senaryo üreteci |
| `08_Utils` | Yardımcı fonksiyonlar |
| `09_Visualization` | 3D görselleştirme |
| `10_Finalized_Analysis` | Yıllık verim ve makale figürleri |
| `11_DataPreparation` | Veri hazırlama betikleri |
| `12_Data` | CSV, MAT veri dosyaları |
| `13_CompareYield` | Karşılaştırma analizleri |
| `14_PaperFigures` | Makale figür betiği |

**Toplam: 57 dosya | 22.4 MB**
